# GitHub Issues - TanStack Query

Repositorio del proyecto del curso sobre TanStack Query con React

## Dev

1. Clonar repositorio
2. Instalar dependencias `npm install`
3. Iniciar servidor de desarrollo `npm run dev`

## Tecnologías usadas

- React
- TanStack Query
- TailwindCSS
- React Router 6+
- React Icons
